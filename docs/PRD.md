# Product Requirements Document

## Project Overview
**Name:** minimal_contact_book
**Type:** web_application
**Created:** 2026-11-01T18:27:55.953787

## Description
Build a minimal contact book. User authentication (email/password). Create a contact with name/email/phone, edit a contact, delete a contact. List all contacts for the logged-in user. (Type: web_app)

## Features
- authentication
- contact_management

## User Stories
### User Authentication
As a user, I want to create an account and log in so that I can access personalized features.

**Acceptance Criteria:** User can register, login, logout, and reset password

## Business Logic
- create_contact
- edit_contact
- delete_contact
- list_contacts
